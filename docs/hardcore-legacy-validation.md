# Hardcore Open-Source & Legacy Codebase Validation

> Stress-testing and hardening report executed with [`scripts/hardcore-legacy-test.py`](../scripts/hardcore-legacy-test.py) against **10 pinned open-source .NET repositories** spanning legacy .NET Framework 4.x / MSBuild 2003 / EF6 / MediatR v2–v3, vertical-slice Razor Pages, Feature Folders, multi-tenant Identity / Blazor Clean Architecture, DDD / Event Sourcing, WolverineFx modular monoliths, legacy `eShopOnContainers`, modern `.NET Aspire` `dotnet/eShop`, and 41-project `nopCommerce`.

---

## 1. Gauntlet Scope & Methodology

Each repository was cloned at a pinned commit SHA (shallow checkout, no `dotnet restore`, no `dotnet build`) and exercised through an 8-stage end-to-end matrix in [`scripts/hardcore-legacy-test.py`](../scripts/hardcore-legacy-test.py):

1. **Dual-backend full scan**: `text` and `roslyn` modes with `--format json --profile`.
2. **Text ↔ Roslyn parity diff**: compares `projects`, `requests`, `handlers`, `validators`, `behaviors`, `dbContexts`, `dataStores`, `notifications`, `endpoints`, `systemEntrypoints`, `integrationFlows`, `serviceProfiles`, and `checks`.
3. **Report & XSS/CSP safety**: `json`, `md`, `--view overview --exclude-tests` (`md` and zero-JS SVG HTML), `mermaid` (plus isolated `.mmd` files with zero unescaped HTML/script tags), `svg` HTML report (no `<script>`, enforced `Content-Security-Policy` `<meta>`, sticky `<nav class="toc">` and `<details>` accordions), `html` report, and `sarif`.
4. **Slice modeling round-trip**: `--draft-slice` up to 10 diverse requests per repo, then `--slice-design <dir> --strict` verification across both `text` and `roslyn` backends.
5. **Proposal evaluation (`--proposal`)**: self-reference handling, layer violation detection (`--fail-on-violations`), $C_a / C_e / I$ coupling metrics, and blast radius.
6. **Blast radius (`--impact`)**: request, handler, entity, and DbContext impact graphs.
7. **Closed-loop TDD & XXE resilience (`--tdd-check`)**: missing TRX exit code `4` under `--strict`, matching failing TRX (`red`/`drifted`/`inconclusive`), and `<!DOCTYPE>` XXE bomb `.trx` rejection (exit code `1`).
8. **Live MCP server & security probes (`--mcp`)**: initializes protocol framing (`Content-Length`), enumerates all **14 tools** (including `get_system_overview`) and **3 workflow prompts** (`model_feature`, `plan_refactor`, `review_architecture_change`), invokes every tool against the live repo, and probes path-traversal / outside-workspace rejection (`../../etc/passwd`).
