## 2. Config Schema (`noctua.schema.json`), `R-COMPAT`, and `R-RELEASE-DOCS`

### 2.1 Config Schema (`R-SCHEMA-CONFIG`)
- Deleted `cqrslens.schema.json`; created `noctua.schema.json` (`$schema: 2020-12`, `$id: https://raw.githubusercontent.com/AbdullahHakima/noctua/main/noctua.schema.json`).
- Covers all `14` rule codes in `KnownRules.All` (added `UnreachableRequest`, `UnpublishedNotification`, `C-BOUNDARY`, `C-SURFACE`, `C-INTENT-STALE` alongside the previous 9 rules).
- Models the complete `intent` section per `F3_INTENT_FORMAT.md`: `modules` (non-empty `projects`/`components` selectors, `propertyNames` non-whitespace, forbidden glob chars `* ? [ ]`), `boundaries` (`from`/`to`/`severity` `warning|error`), `publicSurface` (`endpoints`/`components`/`severity` with non-null array guard), and `ownership` (`propertyNames` + non-whitespace string values).

### 2.2 Compatibility Behaviors (`R-COMPAT`)
1. **Primary & fallback config (`ConfigurationLoader.cs`, `ConfigurationValidator.cs`, `CqrsLensSettings.cs`, `ConfigurationProvenance.cs`, `ScanCommand.cs`, `ScanReporter.cs`):**
   - When `--config` is omitted, checks `<scanRoot>/.noctua.json` first, then permanently falls back to `<scanRoot>/.cqrslens.json`.
   - When **both** `.noctua.json` and `.cqrslens.json` exist in `<scanRoot>`, `.noctua.json` wins (`BothConfigFilesPresent = true`) and `ScanReporter.Write` prints `Config: .noctua.json takes precedence over .cqrslens.json.` to `stdout` (without altering `AnalysisResult.Diagnostics`, `--strict`, or JSON model bytes).
   - `McpScanFingerprintCalculator.cs` hashes both `.noctua.json` and `.cqrslens.json` so edits to either invalidate cached MCP scans cleanly.
2. **Legacy `1.x` artifacts:** `1.1.0`-era `cqrslens-baseline.json` (`schemaVersion: 1`) gates pre-existing errors under `--strict`; `1.1.0` `ARCHITECTURE.json` inputs work with `--diff`; MCP tool names and tool answer prose remain identical (`serverInfo` only changes); `CQRSLENS_ASCII`, `<!-- cqrslens-architecture-diff -->`, `"cqrslens/v1"`, and Action input/output/artifact/category identifiers are preserved.

### 2.3 Release Documentation (`R-RELEASE-DOCS`)
Updated `README.md`, `CHANGELOG.md` (`[2.0.0] - 2026-11-16`), `ROADMAP.md`, and `docs/{ci,configuration,baseline,architecture,analysis-backends,validation}.md` strictly within shipped, verified capability (`H12`).
